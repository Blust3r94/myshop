# MyShop E-commerce

Negozio online: Next.js 14 (App Router) + Prisma + PostgreSQL + Stripe Checkout + Zustand.

## Setup rapido

```bash
npm install
cp .env.example .env   # poi compila le variabili vere
npx prisma db push     # crea le tabelle sul DB
npm run dev
```
